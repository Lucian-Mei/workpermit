## P0 数据结构（单表合并 + 字段扩展）

### [ ] T1 作业票单表字段扩展（workPermits）
**描述**：按方案 B §4，向 `workPermits` 新增从申请单迁移的字段。
**新增列**：`jobName`、`projectName`、`contractorUnit`、`contractorHead`、`contractorPhone`、`materialsList`、`equipmentList`、`managementDept`、`managementPerson`、`hazardTypeList`、`guardianSignatures`、`entryQrToken`、`entryQrUrl`；另加承包商协同字段 `contractorEmail`、`contractorInviteToken`、`contractorInviteExpiresAt`、`contractorSubmittedAt`；续期字段 `renewalCount`、`renewalParentId`。
**验收**：`schema.ts` 编译通过；字段与 `workPermitApplications` 对应关系齐全；无 `SQ-`/`FOR00X` 残留。

### [ ] T2 培训记录改挂 + 有效期
**描述**：`workPermitTrainings` 新增 `workPermitId`（NOT NULL，FK→workPermits）、`validUntil`（培训有效期），保留 `applicationId` 一个版本后删。
**验收**：培训记录可关联到作业票；`validUntil` 可写入/读取。

### [ ] T3 交底/巡检改挂 workPermitId
**描述**：`safetyBriefings`、`inspectionRecords` 的 `applicationId` 改为 `workPermitId`（NOT NULL，FK→workPermits）。
**验收**：交底与巡检均直接关联作业票，不再依赖申请单。

### [ ] T4 新增入厂签到表 entryRecords
**描述**：新建 `entryRecords`：`workPermitId`、`personName`、`idCard`（加密存储）、`entryAt`、`exitAt`、`status`(in/out)。
**验收**：可记录同一票多人多次进厂/签出；身份证加密、打印脱敏。

### [ ] T5 资质证扩展 certType + 必填判断
**描述**：`certificateOcr` 加 `certType`（焊工/吊装/制冷/其他）、`required`（是否强制）。新增按作业内容判断是否必须的逻辑（AI/关键词规则）。
**验收**：作业内容含动火/吊装/制冷等时能自动标记 `required=true`；默认可上传。

### [ ] T6 停用申请单 + 数据迁移
**描述**：停用 `syncWorkPermitsFromApplications`；`workPermitApplications` 表置只读；写存量迁移脚本（未 converted 申请单 → workPermits，按方案 B §4 映射）。
**验收**：启动不再同步申请单；存量数据落到 workPermits；旧表可双读、不参与新流程。

## P1 承包商邀请 + 免登录填写

### [ ] T7 员工创建作业票（单表直建）
**描述**：员工登录创建常规/危险票，**直接建 `workPermits`**，创建即占正式号（`GWP-`/类型前缀，弃 `SQ-`）。危险票表单提供"是否挂靠常规票"选择，挂靠则选已批准未完成常规票并拉取字段（`linkedRoutineId`/`linkedRoutineNo`）。
**验收**：无申请单中间步骤；编号创建即占；危险票挂靠能拉取常规票字段。

### [ ] T8 提交生成承包商邀请
**描述**：员工提交 → 生成 `contractorInviteToken`（72h）+ 邀请二维码；状态→`pending_contractor`；站内通知（邮件后置）。
**验收**：邀请令牌与二维码生成；状态流转正确；二维码可扫码进入填写页。

### [ ] T9 免登录承包商填写页
**描述**：公开页 `/public/contractor-fill/:token`：填监护人信息、作业内容（施工方案）、JSA、风险识别与控制措施 → 提交（`contractorSubmittedAt`），状态→`pending_review`。
**验收**：免登录可填；提交后进审批；令牌单次、过期失效。

### [ ] T10 AI JSA（常规票强制，步骤级定级）
**描述**：常规票与危险票一致执行 AI JSA（`analyzeJsa`），步骤级定级（高/中/低，不评整体风险）；**AI 总次数 ≤3**（首次 + 至多 2 次再分析），人工修订不限次，后端强拦截第 4 次。
**验收**：常规票 `jsas` 必填；每步含风险定级；第 4 次 AI 分析被拦截。

### [ ] T11 资质证自动判断（作业内容驱动）
**描述**：承包商填写时，系统按作业内容判断是否需资质证；证件默认可上传，判断为"必须"时强制（未上传不能提交）。
**验收**：动火→焊工证、吊装→吊装证、制冷维修→制冷作业证等场景正确强制/可选。

## P2 审批 + 批准通知

### [ ] T12 审批链（常规 2 级 / 危险条件化）
**描述**：复用 `approval-routing`；危险票审批链条件化——挂靠=3 级（部门主管→EHS→工程部经理），不挂靠=4 级（部门主管→**区域负责人**→EHS→工程部经理）。删除申请单 `area/dept` 并行会签。
**验收**：常规票 2 级、挂靠危险 3 级、不挂靠危险 4 级（含区域负责人）；审批留痕。

### [ ] T13 批准通知 + 二维码
**描述**：批准后站内通知申请人与承包商，附作业票编号、培训二维码（`trainingQrToken`）；生成入厂码（作业票编号）。邮件后置。
**验收**：批准即生成培训二维码 + 入厂码；通知双方；邮件占位（后置）。

## P3 培训考核 + 入厂签到

### [ ] T14 培训考核（有效期）
**描述**：承包商作业人员扫培训二维码 → 培训考核 → 合格写 `testResult=合格` + `validUntil`（有效期）。**效期内再入厂免考核直接放行**；过期需重新考核。
**验收**：合格留痕 + 有效期；效期内免考核；过期触发重考。

### [ ] T15 入厂签到/签出（状态联动）
**描述**：公开页扫入厂码 → 输作业票编号 + 姓名 + 身份证（仅记录，不实名不拍照）→ 培训校验（合格且未过期）→ 通过写 `entryRecords.entryAt`，状态→`printed`（进行中）。签出写 `exitAt`，全员签出→`paused`（已暂停）。
**验收**：校验通过放行；首签→进行中；全员签出→已暂停；身份证脱敏。

## P4 交底 + 打印 + 检查

### [ ] T16 现场交底 + 签字
**描述**：首次进厂→交底环节；员工登录完成交底，承包商负责人/交底人电子签字（`safetyBriefings.signatures`）。
**验收**：交底记录留痕；签字齐备；一张票一份交底。

### [ ] T17 交底后签字 + 打印（方式 A 为主）
**描述**：作业人员扫员工手机签到码 → 查看风险 → 页面电子签字；签字完成后员工电脑端打印作业票（变量驱动，`fieldKey` 绑定，作业内容/风险/JSA 随输入变化）。离线兜底方式 B（打印件补签后补录）。
**验收**：手机签字留痕；打印模板变量驱动、无写死风险文本。

### [ ] T18 每日现场检查任务
**描述**：交底完成后开启每日检查任务，每天 1 次（`inspectionRecords` 按日去重）；异常可标记 + 拍照。
**验收**：每日检查待办生成；完成率统计（应查天数 vs 实查）。

### [ ] T19 危险作业单独检查
**描述**：`workPermitChecks` 扩展非动火类型；沿用 `checkSlot`/`unlockAt`（动火 0h/1h/3h 定时巡视）。
**验收**：危险票单独检查独立于每日巡检；动火定时槽位解锁正确。

## P5 危险双态 + 续期 + 看板统计

### [ ] T20 危险票双态（挂靠/不挂靠）
**描述**：挂靠票＝常规票子任务（折叠、状态继承、入厂继承，不单独签到）；不挂靠票＝独立主卡片、独立签到、独立状态、强制完整 JSA。
**验收**：两种模式均正确流转；无"无人单独签到"导致状态混乱。

### [ ] T21 作业完成 / 续期
**描述**：作业完成→申请人点完成→`finished`→归档；到期→申请人点续期→生成新票（`renewalCount+1`、`renewalParentId`）→重走审批。作废后保留作废记录（`voided`+`voidReason`）。
**验收**：完成/续期/作废流转正确；续期新票审批独立。

### [ ] T22 看板统一计数 + 挂靠子任务
**描述**：看板按 `workPermits` 主记录计数（挂靠/不挂靠各计 1）；挂靠危险票作子任务折叠展示；状态口径统一（进行中/已暂停/待审批/检查完成率/入厂人次）。
**验收**：统计无重复；挂靠票不占独立主卡片；指标口径与 §7 一致。
