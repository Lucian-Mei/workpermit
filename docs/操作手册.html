EHS 电子化管理系统 · 操作手册

环境 / 健康 / 安全 一体化平台  |  含作业票、隐患治理、培训入厂、现场检查、看板与系统管理

本手册以"流程示意图 + 谁操作 + 怎么操作"形式说明各模块用法（版本对应 2026-08 系统）。

① 登录与账号 ② 角色权限 ③ 作业票流程 ④ 隐患治理 ⑤ 培训入厂 ⑥ 现场检查/签字 ⑦ 微信/匿名上报 ⑧ 管理与看板

1登录与账号安全

所有操作都从登录开始。系统支持"账号/邮箱/手机号"任一方式登录。

  • 任何人（首次进入）
    浏览器打开系统地址 → 进入登录页。输入 登录名 / 邮箱 / 手机号 + 密码，点击登录。
  • 登录失败限制（系统自动）
    10 分钟内同一账号+IP 错 8 次、或同 IP 错 30 次、或同账号错 20 次，将被临时锁定并返回 429，需等待窗口结束。防止密码爆破。
  • 登录后（令牌机制）
    系统签发 30 分钟 有效期的访问令牌（内存自动续期）；刷新令牌以 HttpOnly Cookie 存储，XSS 无法读取、也无法被长期窃取续用。
  • 首次/强制改密
    若账号被标记为"需改密"，登录后自动跳转改密页；修改成功后系统会吊销该账号在其它设备的登录并重发新会话（无需重新登录）。
  • 退出（本人）
    右上角退出 → 前端调用 /auth/logout 吊销当前刷新令牌并清除 Cookie，其它设备不受影响。
账号被管理员停用时，已登录的会话会立即失效（再次访问即 401）。离职/丢机后管理员停用账号即可让所有设备即时下线。

2角色与权限

系统内置 4 类角色，权限由"模块:动作"组成。下表为各角色可做的事。

角色典型岗位核心权限（能做什么）
普通员工作业人员、承包商工人 上报隐患、提交本人作业票申请、参与现场交底/签字、查看数据看板与全员作业看板
审批人（部门负责人）生产/设备/仓储等部门主管 审核本部门作业票、批准危险作业票（会签第 3 步）、部门隐患确认、提交/查看作业票
安全员EHS 工程师、安全环保部 隐患派单/验收/归档、作业票审核与 EHS 审批（会签第 2 步）、现场检查、暂停/作废作业票、看板
系统管理员系统运维/安全负责人 拥有全部权限；管理用户、角色、部门、区域、系统配置、数据备份
提示：角色与权限可在 系统管理 → 角色 中由管理员自定义调整（增删权限点）。

3作业票办理流程（核心）

作业票分"危险作业"（动火、高处、受限空间、吊装、挖掘、临时用电、盲板等）与"常规/非危险作业"。危险作业需 三方会签。

分步操作说明

  • 申请人 提交申请
    菜单 作业票 → 申请：选择作业类型（系统按 GB30871 自动判定是否危险作业）、填写作业内容、JSA 风险分析、安全措施、作业人/监护人、计划时段，可上传附件。提交后进入"待部门审核"。
  • 部门负责人 审核（②）
    菜单 作业票 → 审核：查看本部门待审票，核对措施后"通过/驳回"。非危险作业通过即进入"已批准"；危险作业通过进入"待 EHS 审批"。驳回则退回申请人。
  • 安全员 EHS 审批（③，仅危险作业）
    菜单 作业票 → EHS 审批：审查安全措施与风险等级，通过后进入"待经理批准"。
  • 部门经理 批准（④，仅危险作业）
    菜单 作业票 → 批准：最终批准，状态变"已批准"。
  • 任何人（批准人） 打印 / 下发（⑤）
    在已批准票上点 打印 / 导出，生成作业票并下发现场，状态变"执行中"。
  • 现场多方 交底与签字（⑥）
    现场通过 扫码或现场检查页 完成交底与多方签字（申请人/监护人/监火人/作业人）。危险作业必须签监护人，动火必须签监火人。
  • 申请人/验收人 完工归档
    作业完成 → "完工" → 验收人确认 → "归档"。执行中若需中止，安全员可"暂停/恢复"或"作废"。
非危险作业（如常规作业、断路作业）：仅走 ①→②→⑤，跳过 EHS 审批与经理批准两步。
并发保护：审批采用"状态比较-交换"，同一节点两人同时操作只有一人成功，另一人提示"状态已变更，请刷新后重试"，不会互相覆盖。

4隐患治理流程

隐患从"上报"到"归档"形成闭环，责任人整改、部门确认、安全员验收。

  • 任何人 上报（①）
    菜单 隐患 → 上报，或微信扫码免登录上报：填写隐患描述、位置、照片、风险等级，提交后进入"待派单"。
  • 安全员 派单（②）
    菜单 隐患 → 派单：将隐患分配给责任部门/责任人，状态"整改中"。
  • 责任部门 整改（③）
    菜单 隐患 → 我的：责任人提交整改说明/佐证，状态"待部门确认"。
  • 部门负责人 确认（④）
    部门负责人审核整改结果，通过进入"待验收"，不通过退回整改。
  • 安全员 验收归档（⑤）
    现场/资料验收，通过即"已验收→归档"；验收不通过退回整改（见红色虚线）。安全员也可对简单隐患直接归档。

5培训考试与入厂登记

培训考试

  • 员工/工人 参加培训考试
    开放页 /training/exam：填写姓名、手机号、身份证号、答卷；系统判定合格并生成合格记录（有效期默认 90 天）。
  • 管理员 维护题库/配置
    菜单 培训：维护考题、合格标准、有效期；记录可按身份证号精确查询（避免同名错认）。

入厂登记（承包商工人）

  • 工人 自助登记
    开放页 /public/entry-register：填单位、姓名、手机号、身份证号、签名；系统校验其培训是否合格。
  • 门岗/现场 入厂核验
    扫码 /public/entry/:token 核验登记与培训状态，确认后放行。
身份以身份证号为唯一键：培训合格与入厂登记都按身份证精确匹配，杜绝同名冒领/错认。

6现场检查与免登录签字

涉及多方签字/交底的环节，系统提供"免登录链接/二维码"，外部人员无需账号即可签字。

  • 安全员/审批人 发起现场检查
    在作业票/隐患详情中点"现场检查/签字"，系统生成一次性免登录链接与二维码。
  • 作业人/监护人/监火人/承包商 扫码签字
    用手机扫二维码打开 /public/sign/:token，按角色完成签字/确认；链接一次性、含安全校验，邮件安全网关预取不会误签。
  • 发起人 查看留痕
    签字结果实时回写到作业票/隐患，形成可审计的现场记录。
"全员作业看板"（作业看板菜单）对所有登录用户可见，实时展示各作业票状态与现场进度。

7微信 / 匿名上报

  • 全员（含外部人员） 扫码上报
    通过企业微信/公众号二维码进入 /anonymous 免登录上报页，填写隐患/问题并提交，无需注册。
  • 安全员 接收并处理
    匿名上报进入隐患流程统一治理（同第 ④ 节）。

8系统管理与看板（管理员）

用户管理菜单 系统 → 用户：新增/停用员工账号；停用后其所有会话立即失效。
角色权限菜单 系统 → 角色：自定义角色与权限点组合。
部门/区域菜单 系统 → 部门/区域：维护组织架构与作业区域。
系统配置菜单 系统 → 设置：SMTP 邮件、AI 提示词、二维码、安全抽奖等。
数据备份菜单 系统 → 备份：下载数据库备份 / 同步飞书多维表格（仅管理员）。
数据看板菜单 数据看板 / 年度统计：作业票、隐患、培训等统计图表（需 view_all 权限）。
所有写操作均经后端校验与参数白名单；上传文件限 jpeg/png/gif/webp/pdf 且校验文件头，杜绝恶意文件。
